### 4.1 最終確認：ファーストウェーブのアグロ操作（du-first-wave-aggro-release）

アグロの取得・解除、ミニオンの攻撃先の変更、ウェーブの進む向きは、別の事象として確かめた。

| 確認項目 | 結果 |
|---|---|
| 2019年の記事が想定するアグロの取り方 | 原典は「1st wave のアグロを取り、自軍ミニオンにぶつかるときに外す」とだけ書き、取り方（敵ミニオンを攻撃するのか、近づくだけか）も立ち位置も書いていない |
| パッチ26.10 で削除された条件と同じか | 削除されたのは、敵チャンピオンが味方ミニオンを攻撃したときに、そのチャンピオンがミニオンの優先順位に入る処理。敵ミニオンを攻撃してアグロを取る方法なら、まさにこの条件にあたり、現行では成り立たない。近づくだけで取る方法なら、この削除とは別の条件（「最も近い敵チャンピオン」）だが、ゴースト状態の最初のウェーブは「チャンピオンがかなり近づくまで」敵チャンピオンを無視する（Wiki）ため、どこで取れるかは分からない |
| 最初のウェーブの特殊な処理との関係 | Wiki によると、最初のウェーブ同士がぶつかると、距離に関係なく敵の近接ミニオン3体に攻撃を分ける。アグロを外した後に6体が先頭の1体へ集まることと、この処理のどちらが優先されるかは、Wiki に書かれていない |
| 2026年の仕様で、6体の攻撃の集中を再現できる根拠 | 見つからなかった（Mobalytics・esports.gg は HTTP 403 で未確認。ゲーム内でも検証していない）|
| ウェーブの進む向き | 原典は「ファームしやすい位置に置く（フリーズ）」とだけ書き、進む向きや衝突位置が変わるとは書いていない |

判断：**2019年の歴史的な説明・現行での成立は未確認**として記録する。

- 実験データは削除せず、要旨の先頭に【2019年の歴史的な説明・現行での成立は未確認】と付け、状態を「未検証」（unverified）にした。
- 実用的な手順と誤解されないよう、SHOWCASE_IDS（試験表示）と QUESTION_ENTRANCES（入口）からは外した。詳細の URL を開いても「試験表示の対象にありません」と表示される。
- 現行での成立を確かめるには、ゲーム内での検証か、現行パッチ以降の原典が要る。
- 資料間の比較は追加していない。同じ条件で比べられる目安の組がないため。
- 新しい図解は作っていない。最初のウェーブのアグロ操作は動きの説明があると分かりやすいが、原典に立ち位置・タイミングが書かれておらず、正確な図を描けない。描くなら、ゲーム内で確かめた後にすべき。

- **Yasuo の Q と攻撃手段の選び方**：方向指定のスキルと AA の違い、on-hit と on-attack とミニオンのアグロの区別、Q の最初の命中対象による挙動の違い（チャンピオンかどうかでアグロの扱いが違うという記載がある）、ミニオン越しの Q のアグロ、風殺の壁による飛翔物・遠距離 AA の遮断、AA で圧力をかけてスキルを温存する考え方。「on-hit を持つスキルは必ずアグロを引く」とは一般化しない。根拠の候補は Riot 公式のチャンピオン説明、Wiki（Yasuo・Minion・Attack effects）、Skill Capped の Yasuo トップ解説。今回確認したパッチ26.10 のアグロの変更（敵チャンピオンが味方ミニオンを攻撃したときの動作の削除）との関係を確かめる。
- **CD・一時的な脅威・フォーカスの判断**：スキルの CD で同じチャンピオンの戦闘能力が一時的に変わる。相手がダメージ・CC・逃走スキルを使った直後のトレードの時間（HP・マナ・ウェーブと組み合わせる）。集団戦で、主要な CC を使い切ったタンクと継続して DPS を出す ADC、バーストを使い切ったメイジの、その瞬間の優先度。キルせず低 HP にして後退させる価値。攻撃対象を、届くか・倒せるか・CD がいつ戻るか・味方のフォローがあるかで選ぶ。「観測 → 脅威の変化 → 行動できる時間 → フォーカス・交戦の判断 → 例外」の形で整理する。参考資料の候補は Mobalytics の2本（essential-skills-mid-laners、team comps and teamfighting。どちらも Mobalytics のため、自動取得では 403 になる可能性がある）。既存の du-dopa-tf-fizz-cd-window（フィズの E の CD 中に攻める）、du-trade-checklist（相手のスキルの CD）、du-short-trade-vs-bruiser と重なる部分がある。新しいモデル・CD トラッカー・シミュレーターは作らない。
