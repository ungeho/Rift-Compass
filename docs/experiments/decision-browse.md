# Phase 5D：判断材料（試験）の閲覧機能

- 実施日：2026-10-28
- 目的：Phase 5B の判断材料を、利用者が Rift Compass 上で、出典と条件を確かめながら閲覧できるようにする。自動の推奨・回答・自然文検索は作らない（Phase 5C で、条件の向きや立場を取り違えることが分かったため）。

## 1. 画面と操作

| 画面 | URL | 内容 |
|---|---|---|
| 判断材料（試験）の一覧 | `#/decisions` | 注意書き、Topic での絞り込み（件数つき）、カード（要旨・状況・対象・出典と確認範囲・Topic）|
| Topic で絞り込んだ一覧 | `#/decisions?topic=<Topic ID>` | その Topic と下位の Topic に付いた判断材料だけ。0件なら「このTopicには、試験表示の判断材料はありません」と、その Topic の教材検索への案内だけを出す |
| 判断材料の詳細 | `#/decision/<id>` | 状況と行動、理由（原典の主張／AI の解釈）、成立条件・例外・代替案・代償、パッチへの依存と未確認事項、出典と確認範囲、ほかの判断材料との関係、関連 Topic |
| 資料の詳細（既存）| `#/r/<id>` | その資料を出典とする試験表示の判断材料があるときだけ、「この資料から抽出した判断材料（試験）」の節とリンクを出す |

- 入口は、ヘッダーのナビゲーションに追加した「判断材料（試験）」。教材の検索とは別の画面で、既存の検索は置き換えていない。
- 判断材料の画面には、検索欄を置いていない。探す手段は Topic による明示的な絞り込みだけ。

## 3. 出典・確認範囲の表示

| 区別 | 表示 |
|---|---|
| 出典に明示された主張 | 理由の各行に「原典の主張」のラベル |
| AI による解釈 | 「AI の解釈」のラベル（色を変える）。関係の説明にも「AI の整理」と付ける |
| 全体を確認して記載なし | 「記載なし（全体を確認）」を薄い文字で表示 |
| 一部しか確認しておらず、未読の範囲に記述がある可能性 | 「確認範囲に記載なし（未読の範囲あり）。読んでいない範囲に書かれている可能性があります」 |
| 経験的な主張で、ゲーム内では未実証 | 各判断材料に「経験則・解説者の主張・ゲーム内で未検証」のバッジ。一覧と詳細の冒頭に注意書き |

- 出典ごとに表示するもの：著者、Rift Compass の資料詳細へのリンク（正式資料がある場合）、「原典を開く」（実験データの URL）、確認箇所、確認の範囲（全体／一部と未読の範囲）、作業記録、確認レベル、公開日。
- 確認レベル L3 の説明は、既存のラベル（「要約経由で確認」）ではなく、「AI が原典の本文・字幕を読んで抽出した段階。人による確認や、ゲーム内での検証ではない」とした。Phase 5B では本文を直接読んだため。
- 動画の開始秒のリンクは、実験データの確認箇所に開始秒があるもの（Dopa の1:17）だけに付ける。記事の節へのアンカーは作らない（原典に実在するか確認していないため）。
- 根拠の数は表示しない。関係の節には「関係の数は、根拠の数ではありません。同じ著者の再説明は、独立した根拠として数えません」と書く。

## 4. 実装しなかった機能と理由

| 機能 | 理由 |
|---|---|
| 自然文での判断材料の検索 | Phase 5C の方式C は、条件の向き（有利／不利）と立場（ロームする側／される側）を取り違える |
| 自動回答・戦術の推奨 | 同上。判断材料はどれも解説者の主張で、ゲーム内では未検証 |
| 教材の検索結果への判断材料の混在 | 公開の検索に、取り違えを持ち込まないため |
| 29件すべての表示 | 試験として9件に絞った。選ばなかった理由は §2 |
| 表示用に絞ったデータファイル | データの二重管理を避けるため、実験データをそのまま読み込んだ。そのため JS が増えた（§5）|

## 5. 既存の機能への影響

- 教材の検索：検索エンジン（search.ts）と正式データ（dataset.ts、sample-resources.json）は変更していない。Phase 5A の登録後に保存した84問（既存24問・Phase 2 の18問・自然文12問・確認用30語）の検索結果を比べ、変化は0件。
- 資料の詳細：試験表示の判断材料の出典となった資料（正式資料10件）にだけ、判断材料への案内の節を加えた。ほかの資料の表示は変わらない。リコールの判断材料の出典は正式資料にないため、資料詳細からはたどれない（判断材料の詳細から原典を開ける）。
- JS のサイズ：359KB → 442KB（gzip で 107KB → 128KB）。判断材料の実験データ（29件）をすべて読み込むため。
- 実験データ（decision-units.json）は変更していない。ただし、ファイル冒頭の説明文の「アプリは読み込まない」は、この Phase から事実と違う（閲覧画面が読み込む）。実験データを変更しない方針のため、説明文は直さず、ここに記録する。
- Phase 5B のテスト「アプリは実験データを読み込まない」は、dataset.ts だけを見ていた。今回、確かめる内容を「公開の検索と正式データは実験データを読み込まない。閲覧画面は判断材料だけを読み込む」に改めた。
