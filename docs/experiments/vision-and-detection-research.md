## 2. 情報の種類（同一視しない）

| 種類 | 意味 | ステルスへの効き方 | 例 |
|---|---|---|---|
| **A. エリアの視界** | ある範囲の戦争の霧を晴らし、その中のユニットを見えるようにする（standard sight over an area） | ステルス中の敵は見えない | ラックスの E、アッシュの E、ソラカの Q の着弾前 |
| **B. 対象の可視化** | 命中した敵を一定時間見えるようにする（standard sight of a unit。「revealed」） | **standard sight の可視化は、ステルス中の敵を見えるようにしない**（W-STEALTH） | エズリアルの E、ホライゾン フォーカス、スウェインの W |
| **C. ステルスの看破** | true sight。ステルス中の敵も見える。現行の true sight は、すべて standard sight も兼ねる。ニアサイトは越えられない | 見える | カイ＝サの W、フィドルスティックスの W、タワー |
| **D. 命中の確認（可視化なし）** | 当たったことは分かるが、対象は見えないまま | 当たれば分かる場合がある | エズリアルの Q の CD 短縮、ソラカの Q の Rejuvenation、ニーコの Q の再開花 |
| **E. 存在・位置の推定** | エフェクト・音・HUD・軌跡などから、存在や位置だけが分かる（obscured vision を含む） | 多くは効く | ラックスの Q の檻、レク＝サイの Tremor Sense、ノクターンの Q の軌跡 |

### 視界を妨げるもの・隠れ方の区別

| 用語 | 内容 | 原典 |
|---|---|---|
| 戦争の霧（Fog of War） | 味方が視界を持たない範囲 | W-SIGHT |
| ブッシュ（茂み） | 外から内へは視界を遮るが、内から外へは遮らない。中に視界がないと、中のユニットは見えない | W-SIGHT「Blocking sight」 |
| カモフラージュ | 敵チャンピオンが検知半径の中にいて視線が通る間だけ見える。検知半径は能力ごとに違う（例：800・700・600・500・450・400） | W-STEALTH |
| インビジブル | 検知半径はなく、true sight でしか見えない | W-STEALTH |
| ステルスの罠・ワード | 罠・ワードのステルス。コントロールワード・オラクルレンズ・アンブラルグレイブの true sight は、範囲の中の罠とワードだけに効く | W-STEALTH・W-SIGHT |
| obscured vision | 位置・シルエットだけが見え、対象は選択できない（例：オラクルレンズのドローン、レク＝サイの Burrow） | W-SIGHT |

## 6. 既存モデルでの収録方法

- **資料**：W-SIGHT・W-STEALTH・各チャンピオンの Wiki のページ・Horizon Focus・Oracle Lens を正式資料にする。ラックスは res-wiki-lux が登録済みなので、VS1〜VS5 はすぐに収録できる。
- **ノート**：
  - 定義（§2 の A〜E、ブッシュ・カモフラージュ・インビジブル）と共通の仕組み（VD1〜VD12）は、それぞれ mechanic・source_stated のノートにする。
  - スキルごとの知識（VS）は、そのチャンピオンのノートにし、定義のノートから関係 `applies_to`（定義 → スキル）でつなぐ。**情報の種類は、どの定義のノートにつながるかで表す**（例：エズリアルの Q の CD 短縮 → 「D. 命中の確認」のノート）。
  - 「反応する対象」（チャンピオンのみ・すべての敵など）は、成立条件（conditions_ja）に書く。
  - AI の推論（VS2・VS4・VS7・VS13・VS16・VS20 の後半・VT）は tactical_inference にして、仕様のノートから `reason_for` でつなぐ。ゲーム内で未検証であることを補足に書く。
  - 「バグ」と書かれた挙動（VS24 のカタリナの位置の露出）は、補足に「Wiki はバグと記載」と書く。
- **Topic**：既存の「視界・ワード」（vision）を使う。不足は次のとおり。
  - ステルス・看破の Topic がない（例：stealth。別名：ステルス・透明・インビジブル・カモフラージュ・看破・True Sight）。
  - 「ブッシュ」「草むら」は、vision の別名にない。別名を足すと資料の検索の結果が変わるので、追加するなら影響を確かめる（タワーダイブの Topic と同じ手順）。
  - チャンピオンの Topic は、エズリアル・アッシュ・カイ＝サ・ニーコ・ソラカなどがない。新しい規則（cat-champions の下）で足す。
- **想定する検索での到達（収録後の見込み）**：
  - 「ブッシュに敵がいるか確認できるスキル」：「ブッシュ」が Topic の別名かノートの本文にあれば届く。VT1 のノートが答えに近い。
  - 「視界外でも命中が分かるスキル」：D の定義のノートと、それにつながるスキルのノートに届く。
  - 「ステルス中の敵の位置が漏れる条件」：VT3 のノートに届く。ただし、「漏れる」の主語（自分か相手か）は検索では区別できないので、VT3 と VT4 を別のノートにして、視点の注意（side）と同じく本文の書き出しで示す。
