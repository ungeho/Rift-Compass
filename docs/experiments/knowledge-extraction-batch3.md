## B. 既存知識の再利用の確認（2つの問いへの回答の試作）

新しい事実は作らず、記録済みの知識の ID と既存の判断材料・正式資料だけで組み立てた。「済」は公式・Wiki で確認済み、それ以外は原典の主張。

### 問い1：タワーダイブの成立条件は何か（ウェーブ、タワーのアグロ、相手ジャングラーの位置）

**回答の試作**

1. **相手を倒しきれる体力か**：自分たちが出せるダメージで、タワーの攻撃を受けきる前に倒せるかが最初の条件（K2・H9）。目安は原典で違う：ゆにかは「相手の体力2〜3割以下のときだけ」（K2）、LoL Theory は「スクイシーで60%未満なら2人、40%未満なら CC とサステインがあれば1人」（H9）。**条件（人数・相手の種類）が違うので1つの値にまとめない**。
2. **ウェーブ**：自軍のウェーブがタワー下にいることが前提。ミニオンがいないとタワーへのダメージは80%軽減され（U1 済）、ミニオンがいればタワーはミニオンを撃っている（H8・K3）。押されたウェーブなら、タワーは撃っている途中のミニオンを撃ち終えてから切り替え、ウェーブがないとタワーの対象は自分だけになる（H12）。大きなウェーブでダイブするのはゆにか（K1・第1回 E6）・がりある（`du-slow-push-big-wave-trade`）・LoL Theory（H12）で共通（**経験則の共通点**、著者が違う）。
3. **タワーのアグロ**：
   - タワーがチャンピオンを攻撃していないとき、1400以内の味方チャンピオンにダメージを与えた敵チャンピオンにタワーは切り替える（U3 済）。タワーがすでに別のチャンピオンを攻撃している場合はこの規則の対象外で、その場合の挙動は確認していない。
   - タワーの攻撃は命中ごとに+50%、最大+150%で、5秒でリセット、対象を変えてもリセットされない（U2 済。K5 も同じ仕様を説明 → **公式仕様の一致**で、経験則の裏付けではない）。
   - 実践としては、先にミニオンに攻撃を取らせ、CC と体力のある役がタワーの攻撃を受ける（K3・H8）。向くチャンピオンは原典ごとに違う例（H14・K4）。
4. **相手ジャングラーの位置と援軍**：相手ジャングラーが逆側にいるなら通常は安全、位置が不明で最近自陣側にいたなら危険（H13）。ゆにかは相手のテレポートも確認する（K6）。時間をかけすぎるとカバーが間に合う（K7）。**経験則の共通点**（H13・K6、著者・言語が違う）。有利な側が視界のない中で1人で1対2のダイブをするのは、有利を返す典型（O9。H13 と同じ著者 Griffin Wood なので、O9 は H13 の独立した裏付けには数えない）。
5. **相手のサモナースペル・防御手段**：フラッシュ・ヒール・バリア・クレンズ・イグゾーストはそれぞれダイブを無効にしうる（H10）。ゾーニャ・フィズ E などはダイブを相手の利益に変える（H11）。相手のフラッシュの有無は、第1回 B8・pdvmw ④・`kn-engage-when-flash-down` とも関係する。
6. **タワーそのものを狙うなら時刻**：26.1 時点では、外側のタワーは11:00から耐性が下がり（最大 −60）、プレートは恒久（N3・N4 済・26.1時点）。プレート・Bulwark の耐性は 26.3 で変わった（U6）ので、現行の値は 26.3 以降で確認が要る。

**足りない条件・確認が要るもの**

- ダイブの体力の目安は2つの原典で前提が違い、比べられる共通の基準（レベル・アイテム・タワーの攻撃力）がない。
- 「どのチャンピオンが何発受けられるか」の計算（H6 の「3〜4発で多くのスクイシーが倒れる」）は原典の目安で、タワーの攻撃力の時間変化（Wiki の値）と照合していない。
- 26.3 以降の Bulwark・プレートの耐性の現行値。
- 相手ジャングラーの位置の判断は定性的（「逆側」「最近自陣にいた」）で、時間・距離の基準がない。

### 問い2：育った味方をオブジェクト付近に置くか、スプリットプッシュさせるかを何で判断するか

**回答の試作**

1. **そのチャンピオンの強みがどこにあるか**：「サイドレーンでの強み」か「集団戦での強み」かを理解し、サイドの1対1を主体にするか、主導権を活かして早く合流するかを決める（R6、がりある）。機動力の低いメイジは単独で動かず視界を優先し（R4・P3。**経験則の共通点**、著者・言語が違う）、機動力があり相手ジャングラーと遭遇しても問題ないチャンピオンは単独で視界を取り、ソロキルも狙える（R5）。
2. **スプリットが成り立つ条件**：1対1の脅威、押し続けるウェーブクリア、2人来たときの逃げ（I1・I9）。他の4人が4対5・4対4で戦えること、レーン・アイテムの有利があること（I11）。相手に複数のテレポートがある、1人で倒しに来られる相手がいる、味方が不利すぎるときはしない（I12）。
3. **オブジェクト付近に置く理由**：育った味方をオブジェクトの周りに置き、相手が逆側に動いても元の対面に合わせない（`du-fed-champion-near-objective`、pdvmw ⑤・hfhhp）。理由は、視界の取り合いに参加できない、テレポートで合流してもダメージを出し切りにくい、相手がオブジェクトを捨てて逆側でダイブするとスノーボールが止まること。LoL Theory もドラゴン前に相手のロームを追うとドラゴンを失うとする（P11、同方向）。
4. **時刻と役割**：スプリットする側は、オブジェクトが湧く30〜60秒前にはサイドを押している（I10）。オブジェクトの周りで戦う側は、最低1分前に戦えるかを判断してコンディションを整える（R7・pdvmw ③・第1回 C9）。**役割による時刻の違い**で、矛盾ではない。トップはテレポートを温存してヘラルドに寄れるようにする（第1回 C12）。
5. **誰がゴールドを持っているか**：誰を中心にオブジェクトで戦うかを試合ごとに考える（hfhhp、`du-fed-champion-near-objective` の成立条件）。スノーボールを止めないためには、次のアイテムの山で戦い、主導権をローム・オブジェクトに使う（O7）。
