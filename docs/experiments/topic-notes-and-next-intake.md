## 1. Topic のページの知識ノート

- `TopicPages.tsx` の Topic のページに「この Topic の知識ノート」を加えた。既存の `publicNotes`（`isPublicNote`）と `NoteSummary` をそのまま使う。
- **直接**：その Topic が直接付いた公開ノート。**下位の Topic**：その Topic には付いておらず、下位の Topic だけで付いたノート。経由した Topic の名前（リンク）を示す。直接と下位は重ならない（`notesForTopic`）。
- 旧仕様（current_applicability が superseded）のノートは、それぞれの欄の後ろに並べる。
- **段階表示**：20件ずつ表示し、「さらに○件表示する（残り○件）」で全件まで増やす。件数の上限はない。
- 既存の表示（別名・上位の分類・下位の Topic・絞り込みの検索・判断材料へのリンク・資料の一覧）は変えていない。ノートの欄は、判断材料へのリンクと資料の一覧の間に置いた。

## 2. チャンピオン Topic の多重親の検証（採用していない）

既存の3件（champ-jax・champ-veigar・champ-twisted-fate）に、元の親を残したまま cat-champions を親として足す案を、データの作業用のコピーで試した。

| 影響 | 結果 |
|---|---|
| 資料の検索（評価の質問・Phase 2 の42問） | 変化なし |
| Topic での絞り込み | cat-champions だけが変わる（5件→13件。ベイガー・TF・ジャックスの資料が加わる）。ほかの Topic は同じ |
| 散策の距離の分類 | **45 Topic のうち14で変わる** |

散策の分類の変化（近い／中間／遠い）：

| Topic | 現在 | 多重親にした場合 |
|---|---|---|
| チャンピオン別 | 24 / 2 / 169 | 34 / 133 / 28 |
| 専門家・高レート解説 | 38 / 9 / 148 | 38 / 35 / 122 |
| ベイガー | 1 / 37 / 157 | 1 / 63 / 131 |
| ツイステッド・フェイト | 7 / 33 / 155 | 7 / 59 / 129 |
| ジャックス | 2 / 135 / 58 | 2 / 145 / 48 |
| 通常攻撃の無効化 | 5 / 132 / 58 | 5 / 142 / 48 |
| CC（行動妨害）・トレード | 中間 +10 | |
| ゲームの基本仕様・レーニング | 中間 +10・+8 | |
| マルザハール・モルデカイザー・ゼド・ラックス | 中間 各 +10 | |

- 理由：散策の「中間」は、近い Topic の上位の Topic の配下すべて。チャンピオン Topic が2つの親を持つと、片方の親の配下（例：専門家・高レート解説のすべての資料、チャンピオン別のすべての Topic）がもう一方の側から「中間」になる。チャンピオン別では、中間が2件から133件に増え、「遠い」がほとんどなくなる。
- **判断**：散策の距離の意味（近い・中間・遠いの区別）が大きく変わるので、今回は採用しない。採用するなら、散策の「中間」の決め方（例：大分類の配下を中間に数えない、または親を1つだけ使う）を先に決める必要がある。
- そのため、チャンピオン Topic の親の構造は、引き続き2通り（新しい4件は cat-champions、既存の3件は元の親）。
