# Phase 6A：既存の判断材料の試験表示を増やす

- 実施日：2026-10-28
- 目的：抽出済みの判断材料38件のうち、未表示の24件から、プレイヤーの判断の改善に役立つものを選び、閲覧画面（Phase 5D・5E の仕組み）で表示する。
- 結果：5件を加え、試験表示を14件から19件にした。新しいデータ構造・画面・検索機能は追加していない。
- 変更していないもの：正式資料75件、教材の検索（search.ts）、正式データ、目安16件・比較3組、Phase 5C の質問と評価。

## 1. 選び方

未表示の24件を、既存の抽出記録（decision-units.json・decision-criteria.json）と、Phase 5D・5E の「選ばなかった理由」から見直した。重視したもの：

- 何を観測すればよいかが具体的
- 判断が変わる条件・例外が書かれている
- 行動の選択肢と代償が書かれている
- 既知の原則を、実行できる判断基準にしている
- 表示中の14件にない場面、または別の著者の視点
- 表示中の14件と重なりすぎない

数値があることだけでは選んでいない。Phase 5D の「1出典1件」の方針は、今回は重なりの判断に使い、同じ記事でも場面が違うものは候補に残した。

### du-plates-vs-clean-recall（Phase 5B の判断材料）

|---|---|---|
| 要旨（statement_ja）| タワープレートのために、時機の良いリコールを犠牲にしない。押すなら…| タワープレートのために、時機の良いリコールを犠牲にしない（原典は、きれいなリコールの方が「たいてい」価値が高いとする）。押すなら…|
| 行動（action_ja）| きれいなリコールを優先する | きれいなリコールを優先する（原典は「たいてい」とし、常にとはしていない）|

- 観測・理由・関係は変えていない。
- Phase 5C の方式C の評価結果は、訂正の前後で同じ（13問の結果を比べて変化なし）。質問・期待値は変えていない。

## 6. 画面の変更

- `src/data/decisions.ts` の SHOWCASE_IDS に5件を加えた。画面のコードは変えていない。一覧の件数は自動で19件になる。
- 加えたことで、次の表示が変わる：
  - 一覧・Topic の絞り込みに5件が出る。
  - 表示中の判断材料の「ほかの判断材料との関係」で、加えた材料へのリンクが出る（これまでは「試験表示の対象外」）。該当するのは3か所：du-mid-recall-4th-wave と du-recall-resource-threshold から du-plates-vs-clean-recall へ、du-mid-lvl1-no-hard-push から du-half-push-gets-frozen へ。
  - Lv2 の比較（cmp-lv2-minion-count）で、ボットの目安から du-lv2-duo-minion-count へのリンクが出る。
  - 出典の正式資料の資料詳細に、判断材料への案内が増える。対象は res-lg-wftjm、res-lg-kjumg（既に案内あり）、res-loltheory-wave-2026、res-dignitas-wave-2019、res-lg-mmlgg。du-lv2-duo-minion-count の出典（vdxoz）は正式資料にないので、資料詳細からはたどれない。
- 5件の関係先のうち対象外のもの（du-roam-counter-action → du-jungler-hovering-trap の1か所）は、これまでどおり内容を出さず「試験表示の対象外の判断材料」と表示する。
- 資料間の比較の内容（数値・判定・判断できない点）は変えていない。Lv2 の比較の判定は「矛盾かどうか判断できない」のまま。
