## C-1. 通常攻撃（AA）の先行入力

| ID | 知識 | 種類 | 確認 |
|---|---|---|---|
| IB1 | 攻撃するにはまず対象を「取得」する。取得は、攻撃の命令（右クリック・アタックムーブで対象を選ぶ）、自動の対象取得、挑発・狂乱で起きる | 仕様 | 済（W2 Acquisition） |
| IB2 | 対象が攻撃射程の内なら攻撃し、外なら**自分の攻撃射程が対象の当たり判定に届くまで対象に向かって歩き、届いたら止まって攻撃しようとする** | 仕様 | 済（W2） |
| IB3 | 取得は、新しい対象の命令、攻撃の取り消し（どの方法でも）、対象が無効になる（死亡・対象指定不可）まで続く | 仕様 | 済（W2） |
| IB4 | 攻撃の振りかぶり（windup）は、別の命令、攻撃者か対象の死亡、対象が対象指定不可になる、対象が遠くへ離れる、対象が見えなくなる、で中断される。振りかぶりを始めた後の通常攻撃は、これらの例外を除いて避けられず、対象を見失わない | 仕様 | 済（W2） |
| IB5 | 取得した対象に向かって歩いている途中で対象が見えなくなると、最後に見えた位置へ歩き続ける。その移動が終わる前に対象が再び見えると、再び対象に向かって攻撃する | 仕様 | 済（W2） |
| IB6 | 動く対象への攻撃を自動の追跡に任せると、対象の確認の処理のせいで移動・攻撃に遅れが出ることがある。**対象が短時間に射程の内外を出入りすると特に目立つ**。手動で移動と攻撃の命令を繰り返す方が速く正確（カイティング） | 仕様 | 済（W2） |
| IB7 | 振りかぶりの完了の1ティック（0.033秒）前からは、移動・ホールド・停止の命令で攻撃を取り消せない。攻撃の発射後にも1ティック、新しい命令を受け付けない | 仕様 | 済（W2） |
| IB8 | アタックムーブ（A＋クリック、Shift＋右クリック）は、目的地へ向かいながら取得範囲内の敵を探す。対象を直接選べば通常の攻撃命令と同じ。「カーソル位置にアタックムーブ」を有効にすると、カーソルの周り（攻撃射程の内か近く）で探す | 仕様 | 済（W2） |
| IB9 | 茂みや戦場の霧の中から攻撃すると、攻撃の完了後2秒間、攻撃者の周り300が見えるようになる | 仕様 | 済（W2 Vision） |
| IB10 | 「AA 射程外の敵に攻撃の命令を先に出しておく」と、IB2 により自分は敵に向かって歩き始める。敵がダッシュで近づけば、射程が届いた時点で攻撃しようとする（命令は IB3 の条件まで続く） | AI（IB2・IB3 からの組み立て） | 仕様の組み合わせ。ゲーム内では未確認 |

| IB12 | 先に命令を出すと、待っている間に自分が敵へ歩いて近づく（IB2）。射程を保ちたい・タワー下にいたい・敵のスキルの射程に入りたくない場面では不利になる | AI（IB2 から） | 未確認 |

## ダッシュ・リープ・ブリンクの区別

| ID | 知識 | 種類 | 確認 |
|---|---|---|---|
| IB15 | ダッシュは、間の距離を移動しながら目的地・方向へ動く。ブリンクは、間を通らずに瞬間的に動く | 仕様 | 済（W3・W4） |
| IB16 | **見た目が「ジャンプ」でも、移動を伴うものはすべてダッシュに分類される**。ゲームは高さを扱わないので、跳んでいるユニットもスキルショットなどでは地上にいる扱い | 仕様 | 済（W3） |
| IB17 | 「リープ」は Wiki のダッシュの分類の名前ではない（W3 はダッシュを自動対象・方向指定・位置指定に分ける）。リープは見た目の呼び方で、内部ではダッシュ | AI（W3 の分類から） | Wiki の記載の範囲で整理。用語の公式の定義は未確認 |
| IB18 | ダッシュは、ノックダウン（例：ベイガーの E）で途中で止まる（ディスプレイスメント無効・CC 無効・スペルシールド・対象指定不可を除く）。打ち上げ・サスペンションも割り込む。一部のダッシュは拘束・変身でも止まる | 仕様 | 済（W3） |
| IB19 | ダッシュ・ブリンクは、グラウンド・ルートの間は使えない | 仕様 | 済（W3・W4） |
| IB20 | ブリンクは間を通らないので、ベイガーの E（イベントホライズン）の壁などを越えられる（カミールの R の壁は例外） | 仕様 | 済（W4） |
| IB21 | フラッシュはブリンク。使うと向きが移動した方向に変わる。射程より遠くを指すと最大距離で使う。常にクイックキャスト | 仕様 | 済（W5） |
